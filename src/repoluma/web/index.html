    Getting around

    Wheel / pinchZoom around the pointer. Detail appears as things get larger.
    Drag, arrow keysPan. Panning keeps the zoom, so nearby regions show the same depth.
    ClickSelect and inspect. Double-click or Enter zooms to it.
    Click a code paneActivates it: wheel scrolls code and text can be selected. Esc releases it.
    Ctrl + wheelAlways zooms, even over an active code pane.
    Shift + wheelPan sideways.
    /Search labels, ids, summaries and file paths.
    Files tabEvery file and the area it belongs to. Click a file (or the file name above a code pane) to see which pane shows each of its lines.
    0 / b / uWhole map / back to previous view / select the containing item.
    n / pNext / previous step of the active flow.
    cCopy the selection as text for a coding agent (ids, source, relationships, link).

    The URL always describes the current view, selection, flow and layers: share it or paste it to an agent.
